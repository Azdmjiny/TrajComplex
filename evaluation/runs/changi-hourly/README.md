## Saved-result reproduction

```bash
python evaluation/code/report_changi_hourly.py --input /local/changi-dedup-evaluation --preprocessing position-dedup --output /new/local/report
```

The builder validates 48 full results and 6,600 existing subset draws. It generates four figure sets and a report; no checkpoint, raw downloads, Encoder, D calculation or new sampling is used. The output directory must not exist. Use `--preprocessing original` and the original local package to report the 6,200 original draws. The named policy must match the saved population. Text is generated by `hourly_report_text.py`; raw input screening is not changed by these reporting commands.

Required local input: `results/one-hour-summary.json`, `results/background-counts.json`, and all 48 `results/DATE-1h-HH-all-attempts.json.gz` files. The deduplication validation, source processing code and rerun execution provenance remain in the local evidence packages. A clone alone does not contain the hourly input data.

## Publication scope

Only code, reports and PNG/SVG/PDF figures are presentation artifacts. Embeddings, draw assignments, complete D attempts, QC evidence and manifests remain local. No raw observations, model weights or authentication material are copied here.

For saved-record tests set `CHANGI_HOURLY_INPUT` to the selected local package and `CHANGI_HOURLY_POLICY` to `position-dedup` or `original`. Run `python -m unittest discover -s evaluation/code -p "test_changi_hourly_report.py"`.

Only exactly repeated horizontal observations are deduplicated. All original altitude observations, age/gap checks and other thresholds remain. The original 1,434 accepted arrays and embeddings are unchanged; 263 additional aircraft-hours pass. This does not modify Holding or Vectoring input preprocessing.
