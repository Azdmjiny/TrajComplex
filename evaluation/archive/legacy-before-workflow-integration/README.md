# Historical root-level evaluation files

Archived during workflow integration. Current results remain under [runs](../../runs/README.md), and current conclusions are in the [combined report](../../report.md).

- `committed/`: exact Git blob contents from commit `b7dacf336172f52a6e007a525c66d0a35de5b33e`.
- `local/`: exact pre-cleanup working files, including previously untracked method reports and screening summaries.
- [inventory.json](inventory.json): original path, snapshot, SHA-256 and tracked status for every file.
- [published-before.json](published-before.json): pre-cleanup hashes of the published evidence.

These snapshots deliberately retain both versions of modified files. The local root run manifest identifies the old five-second checkpoint and an earlier continuous generator; later population/peak/direction screening records coexist with it. Do not treat this directory as a single reproducible experiment, or combine its generic figures with current results. Historical reports describe the stage at which they were written; statements such as “control not yet run” are not current status. Original source paths in manifests are provenance, not current entrypoints.

No numerical files were overwritten or merged. No unique historical record was deleted. Duplicate snapshot content is retained to preserve relative report/figure links and exact provenance.
