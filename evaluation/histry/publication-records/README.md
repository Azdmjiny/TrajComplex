# Historical publication records

`publication-manifest.json`, `publication-checks.json` and `maintenance-checks.json`
are saved audit records from earlier publications. Their bytes and original
paths are retained; they are not a fresh all-files check of the reorganized tree.
`runs-index.md` preserves the previous shared-run index.

Use [the relocation map](../organization-map.json) for original paths and
`python evaluation/code/check_layout.py` for the current read-only layout check.
